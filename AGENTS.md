# wbstat — правила для агентов

## Область

Работа только внутри `/srv/projects/wbstat`.

## Границы

- Не трогать соседние проекты в `/srv/projects/`.
- Не менять `/srv/platform` и `/srv/docs`, если пользователь явно не попросил инфраструктурную задачу.
- Черновики и неутверждённые требования — в `docs/drafts/`.
- Секреты не коммитить; реальные значения — только в `envs/*/`, вне git.

## Где что лежит

- код и статика: `app/`
- compose: `infra/compose/`
- эксплуатация: `docs/RUNBOOK.md`, `ops/`
